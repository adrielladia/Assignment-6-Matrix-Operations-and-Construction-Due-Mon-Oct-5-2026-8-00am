# Assignment-6-Matrix-Operations-and-Construction-Due-Mon-Oct-5-2026-8-00am
R script for LIS4370 Assignment #6. Covers matrix addition and subtraction with two 2x2 matrices, building a 4x4 diagonal matrix with diag(), and constructing a custom 5x5 block-structured matrix using diag(), cbind(), and rbind(). Includes an alternative index-assignment method to verify the 5x5 result.
